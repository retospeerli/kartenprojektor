# Grossrelief-Kartenprojektor v5.10

Diese Version verwendet für die Gewässerebene strikt nur diese zehn Gewässer:

- Zürichsee
- Hüttenersee
- Ausee
- Teufenbachweiher
- Sihl
- Aabach
- Gulmenbach
- Meilibach
- Riedbach
- Zopfbach

Andere Rinnsale sollen ignoriert werden.

Die Tastenbelegung bleibt bestehen; Taste 3 schaltet die Gewässerebene, Taste 7 die Namen dazu.
